Project Overview

The Supermarket Sales Dashboard is a business intelligence project developed using Microsoft Power BI to analyze and visualize supermarket sales data. The dashboard provides meaningful insights into sales performance, customer behavior, product demand, and business trends through interactive visualizations.

Objectives
Analyze supermarket sales performance
Track profit and revenue trends
Identify top-selling product categories
Understand customer purchasing behavior
Create interactive and user-friendly dashboards
